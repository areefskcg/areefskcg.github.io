📖 Overview

This repository contains 12 specialized AI agents designed to accelerate SAP Business One development across the full technology stack. These agents integrate with GitHub Copilot in VS Code, IntelliJ IDEA, and Visual Studio, providing intelligent assistance for code generation, testing, migration, documentation, and debugging.

Each agent is a domain-specific expert that understands SAP Business One architecture, coding patterns, and business logic across UI5, Java/Spring Boot, and C++ layers.

🛠️ Development Agents

Development

1 JavaAgent

Purpose: Specialized assistant for SAP Business One WebClient Java development
Key Capabilities:
  • Creates Business Objects (BOs) from database tables
  • Generates Spring Boot service layer code
  • Implements FlowStage validation patterns
  • Supports Smart BO creation pipeline with C++ to Java migration
  • Generates DAO, Service, and Controller layers
Example Usage:
Create BO for table: ODOC
Feature: Invoice Management
Mode: FULL

2 UI5 Coding Agent Pipeline

Purpose: UI5 frontend development specialist for SAP Business One WebClient
Key Capabilities:
  • Generates UI5 views, controllers, and fragments following SAP Business One patterns
  • Creates API endpoint bindings and client-side validations
  • Implements custom widgets and controls
  • Supports Smart BO Creation pipeline (receives JavaBoContext from JavaAgent)
  • Generates complete UI5 stack: API services, detail views, fragments, i18n files
Example Usage:
Create UI5 frontend for BO: Invoice
Feature: Invoice Management
Include: Detail view, General tab fragment, API service
Handoff Support: Automatically receives JavaBoContext from JavaAgent in Smart BO pipeline

3 CPP to Java Migration Agent Migration

Purpose: Migrates business logic from C++ MFC desktop application to Java web application
Key Capabilities:
  • Extracts validation and calculation logic from C++ codebase
  • Maps C++ patterns to Java FlowStage, Service, Controller, and BO components
  • Pre-refactors C++ code before translation
  • Generates MigrationContext JSON for Smart BO creation
  • Converts pointer operations, control flow, and MFC patterns to Java equivalents
Example Usage:
Extract logic for BO: Invoice
From C++ file: PA4101.c
Generate MigrationContext for JavaAgent
Handoff Support: Automatically hands off to JavaAgent with MigrationContext

4 CppRefactor

Purpose: Bi-directional C++ PA (Presentation) to PO (Presentation Object) refactoring
Key Capabilities:
  • Extracts business logic from PA layer to PO layer (removes UI dependencies)
  • Wraps PO logic into PA layer with UI scaffolding (reverse direction)
  • Converts grid and data access operations between layers
  • Preserves calculations and validations while removing PFORM, GRID, ITEM calls
Example Usage:
Refactor PA → PO: PA4101.c
Extract all business logic
Remove UI dependencies

🚀 Quick Start

Prerequisites

  • GitHub Copilot subscription
  • One of the following IDEs:
    • VS Code (recommended) - with GitHub Copilot extension
    • IntelliJ IDEA - with GitHub Copilot plugin
    • Visual Studio - with GitHub Copilot extension

Setup Steps

  1. Clone the repository containing these agents
  2. Open the workspace in your IDE
  3. Invoke an agent using GitHub Copilot Chat:
    In VS Code:
    @workspace /mode <agent-name>
    In IntelliJ:
    Switch to agent mode via Copilot settings
  4. Provide context and let the agent assist you

Example Workflow: Smart BO Creation Pipeline

This is a powerful multi-agent workflow that creates a complete feature from C++ business logic:

1. User Prompt:
"Create Smart BO for Invoice Management from PA4101.c"
2. CPP to Java Migration Agent:
  • Extracts business logic from C++
  • Generates MigrationContext JSON
  • Auto-hands off to JavaAgent →
3. JavaAgent:
  • Creates Java BO, Service, FlowStage classes
  • Generates JavaBoContext
  • Auto-hands off to UI5 Coding Agent →
4. UI5 Coding Agent:
  • Creates complete UI5 frontend
  • Generates views, controllers, API services, i18n files
  • Pipeline complete! ✓
Result: Complete feature implementation across all layers from a single prompt.
