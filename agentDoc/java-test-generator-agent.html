Testing Agent

Java Test Generator

Generates comprehensive Spock / Groovy test cases for Spring Boot Java service classes following CTO platform patterns, then validates them via logical trace-through and produces a verification report.

ID Java Test Generator Model auto Framework Spock / Groovy Tools read, editFiles, search

Description

This agent reads the full service code, analyzes every method, creates exhaustive test cases following established patterns, validates them internally via a logical walkthrough, and produces a verification report — all without executing the test suite.

When to Use

  • Generate a full Spock test spec for a Java service class.
  • Create missing test cases for uncovered service methods.
  • Validate existing test files against the service code for correctness.
  • Produce a coverage and validation report without running tests.

Five-Phase Pipeline

PhaseActivity
1. ReadRead full service code and instruction file — every line, no skipping.
2. AnalyzeClassify every method, map dependencies, and identify branches.
3. GenerateProduce a Spock test file following all instruction patterns.
4. ValidateTrace random inputs through the service logic and compare to test assertions.
5. ReportOutput a verification report with pass / fixed / attention per method.

Analysis Detail

  • Dependency inventory — Table of every injected field and inherited base dependency.
  • Method classification — Visibility, inherited calls, DAOs used, branch count, and test instance type.
  • Branch mapping — Every conditional branch becomes at least one test case.
  • Risk assessment — Flags complex DAO chaining, mixed inherited/local logic, and subtle differences.

Validation Classification

ResultMeaning
PASSTrace confirms all assertions are correct.
FIXEDA mismatch was found and the test was corrected.
ATTENTIONCorrectness cannot be confirmed; flagged for manual review.

Non-Executing Validation

Phase 4 is a logical trace-through — the agent mentally executes the service method with random inputs and compares outcomes to assertions rather than running the code.
