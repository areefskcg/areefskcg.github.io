Documentation Agent

Module Level Documentation Agent

Generates comprehensive module-level documentation by analyzing codebases — extracting core and supporting business objects, data flow, functional flow, and database information, plus a validation report.

ID Module Level Documentation Agent Model auto Output Markdown Multi-language C++, Java, JS, SQL

Description

This agent analyzes software codebases and generates comprehensive module documentation in Markdown, including detailed business-object analysis, data flows, functional flows, database schema information, and validation reports.

Workflow

  1. Confirm scope — Module name/path, primary languages, boundaries, and codebase/schema locations.
  2. Analyze codebase — Walk the folder structure, identify source files, and map class/function hierarchies.
  3. Identify business objects — Distinguish core (transaction-level) BOs from supporting (child/lookup) BOs.
  4. Extract data flow — Trace data from UI → Service Layer → API → Database.
  5. Document functional flow — Identify major workflows (Add, Update, Delete, Approve) and their business rules.
  6. Extract database information — Tables, key columns, relationships, constraints, and stored procedures.
  7. Generate documentation — Produce the main document and a validation report.

Output Files

FileContents
{module}_documentation.mdBusiness overview, BOs, functions, data & functional flows, schema, business rules, dependencies, and inferred requirements.
{module}_validation_report.mdCoverage analysis, quality metrics, completeness percentage, gaps, and improvement recommendations.

Both files are saved to the reports_module/ folder.

Multi-Language Support

  • C++/C layer — Core business logic and validation rules.
  • Java layer — Service APIs and transformations.
  • UI5 / JavaScript layer — User workflows and form handling.
  • SQL layer — Data persistence and relationships.

Success Criteria

Main documentation covers module purpose, all BOs, detailed flows, complete schema, business rules, and 3–5 key workflows. The validation report targets >85% completeness with gap identification.
