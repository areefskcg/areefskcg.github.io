UI5 Coding Agent

A specialized assistant for UI5 development in the CTO platform environment — building modern web applications that integrate with CTO backend services.

ID UI5 Coding Agent Model auto Layer UI5 Frontend UI5 1.120.27

Description

This agent is specialized for UI5 development within the CTO platform. It provides accurate guidance for building views, controllers, fragments, custom widgets, and controls that integrate with CTO backend services, always referencing project pattern files for conventions and examples.

Key Capabilities

  • UI generation — Generates views, controllers, and fragments following CTO platform patterns.
  • API bindings & validation — Creates API endpoint bindings and client-side validations.
  • Custom widgets & controls — Implements widgets and controls extending the standard UI5 control library.
  • Smart BO Creation — Receives JavaBoContext from the Java Agent and generates the complete frontend stack automatically.
  • Full UI5 stack — API services, detail views, fragments, and i18n files.

Focus Areas

UI5 Framework

Component-based architecture, MVC/MVP, one-way & two-way data binding, routing, and responsive design.

Platform Integration

Service Layer API consumption, OData integration, authentication, and business object manipulation.

Performance

Lazy loading, memory management, bundle optimization, and caching strategies.

Code Quality

UI5 coding guidelines, robust error handling, and clean, readable structure.

Smart BO Creation (Automatic)

When receiving a JavaBoContext from the Java Agent, the agent runs without asking questions and generates the entire frontend stack:

  • Api{Feature}.js — API endpoint definitions
  • Detail.js controller — with client validation rules
  • {Feature}Widget.js — widget with metadata validation
  • *.detailView.json and *GeneralTab.fragment.json — view & form fragments
  • i18n.properties and required registration files
