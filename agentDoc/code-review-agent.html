Code Review Agent

A full-stack (frontend + backend) code review agent for the CTO platform. It validates structure, correctness, architecture compliance, security, and performance, then produces a detailed report with an interactive fix-selection list.

Model auto Scope Frontend + Backend Output Markdown report

Description

The Code Review Agent reviews all files in a pull request based on the scope defined by the user. It detects the language of each file first, loads only the matching instruction file(s), and produces a comprehensive review covering violations, severity, explanations, and prioritized fix suggestions.

Review Scoping

Before any review, the agent determines the review mode to avoid unnecessary full-file passes:

ConditionReview mode
Whole file(s) / PR-level reviewFull Review — exhaustive multi-pass
Named specific function(s)Function-Scoped Review — fast path

Severity Levels

SeverityExamples
BlockerSecurity vulnerabilities, crashes, data loss, authentication bypass.
CriticalLogic errors, resource leaks, concurrency issues, injection risks.
MajorPerformance issues, bad patterns, missing error handling, API misuse.
MinorUnused imports/variables, naming violations, dead code, style issues.
InfoStyle suggestions, alternative approaches, readability improvements.

Multi-Pass Exhaustive Strategy

  • Pass 1 — Full sequential review of every line, accumulating all findings.
  • Pass 2 — Verification sweep for missed unused imports, dead code, and naming/length violations.
  • Pass 3 — Final reconciliation for large files to ensure every logical block was checked.

Determinism

The agent follows a fixed evaluation order (imports, declarations, methods) and severity checklist so two runs on the same unchanged file produce the same findings in the same order.

Outputs & Interactive Fixes

  • A detailed review report saved to /code_review_reports.
  • An interactive fix-selection list presented in chat — the user selects which fixes to apply.
  • Applied changes logged to <filename>_coderev_log.md in the reviewed file's parent directory.
