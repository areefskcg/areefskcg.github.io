Development Agent

Java Agent

A specialized assistant for CTO WebClient Java development — Business Object creation, code generation, validation, refactoring, and debugging.

ID JavaAgent Model auto Layer Java / Spring Boot Tools read, edit, search, execute, agent

Description

The Java Agent is a full-spectrum Java development assistant for the CTO WebClient backend. It provides accurate guidance for creating Business Objects, generating services, controllers and mappers, validating and fixing code, refactoring, debugging, and writing tests. It always references project instruction files for CTO-specific patterns and conventions.

Key Capabilities

  • Business Object creation — Builds layered-architecture BO components that integrate with the CTO Service Layer APIs.
  • C++ Documentation → Java code generation — Reads generated C++ documentation and produces equivalent Java implementations.
  • Smart BO creation — Creates BOs with business logic migrated from C++ and passes context downstream to UI5.
  • General code generation — Services, controllers, DAOs, mappers, Feign clients, configs, exception handlers, and utilities.
  • Code validation & auto-fix — Detects issues, classifies severity, generates fixes, and produces structured Markdown reports.
  • Refactoring & debugging — Improves structure, extracts methods/classes, and diagnoses compilation, runtime, wiring, and SQL errors.
  • Testing — Delegates to the Java Test Generator to produce Spock specifications and JUnit 5 tests.

Handoffs

C++ to Java MigrationExtract validation, calculation, and business logic from the C++ codebase as a MigrationContext JSON.
UI5 Coding AgentCreate the UI5 frontend for a BO using the JavaBoContext (field bindings, validations, API endpoints).
Java Test GeneratorGenerate Spock / Groovy tests for the service class.

Outputs

  • Complete BO stack: domain classes, DAOs, services, controllers, mappers, Feign clients.
  • Validation reports saved as {ClassName}-ValidationReport.md under a documentation folder.
  • Structured JavaBoContext JSON for handing off to the UI5 layer.

Smart BO Pipeline

When a MigrationContext is received, the agent always continues the pipeline by generating Java BO files and handing off to the UI5 Coding Agent — it never stops after generating Java files.
