Migration Agent

C++ to Java Migration Agent

Converts business logic from a C++ MFC-based desktop application into a Java web application following FlowStage, Service, Controller, and BO architectural patterns.

ID CPP to Java Migration Model auto Mode Expert / Architect Tools editFiles, search, read, agent

Description

In expert mode the agent behaves like a senior architect: it performs deep logic analysis, refactors C++ code before translation, maps components intelligently, validates completeness, and produces architecture-compliant Java. Its primary focus is migrating validation and calculation logic while adhering to the target Java project's architectural patterns.

Migration Workflow

  1. Expert reasoning — Understand intent, classify logic (validation, calculation, transformation, event, DB), and detect hidden dependencies and side effects.
  2. Pre-refactoring — Split oversized functions, normalize conditions/loops, extract reusable computations, and replace pointer operations with clean equivalents.
  3. C++ logic extraction — Extract validation/calculation logic, control-flow paths, inputs, outputs, and referenced fields.
  4. Architecture mapping — Map C++ patterns to Java components using established migration patterns.
  5. Java code generation — Produce FlowStage, Service, BO, and Controller code from templates.
  6. Post-migration validation — Compare every C++ branch with the Java result to ensure no logic path is missed.
  7. Migration logging — Record each step and method status for resumable, incremental migration.

Smart BO Creation Flow

When invoked as part of the Smart BO Creation pipeline, the agent:

  1. Extracts validation, calculation, and business logic from the C++ codebase.
  2. Generates a structured MigrationContext JSON (validation rules, calculation methods, business rules, field mappings, client validations, enum mappings, and child-table logic).
  3. Automatically hands off to the Java Agent to generate Java BO files incorporating the extracted logic.

Pipeline Continuity

The agent does not stop after generating the MigrationContext — the pipeline continues to the Java Agent, and onward to the UI5 Coding Agent.

Final Response Requirements

  • Final migrated Java code
  • Refactored C++ interpretation
  • Logic comparison table (C++ vs Java)
  • Architecture mapping summary
  • Manual review notes
  • Migration log update
