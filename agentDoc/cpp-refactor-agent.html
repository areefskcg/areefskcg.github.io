C++ Refactor Agent

A bi-directional C++ refactoring agent for the CTO platform — extracts business logic from the presentation (PA) layer to the business-object (PO) layer, or wraps PO logic into a PA layer with UI scaffolding. Auto-detects file type and refactoring direction.

ID CppRefactor Model auto Layer C++ Tools editFiles, search, read, execute

Description

This agent specializes in PA↔PO layer refactoring within the CTO platform C++ codebase. It reads every line of large source files (routinely 5,000–15,000+ lines), determines the refactoring direction, and transforms code while preserving business logic, transaction boundaries, and error-handling patterns.

Mandatory Full-File Reading Protocol

The agent must read every single line of every referenced source file in sequential ~500-line chunks. Skipping, summarizing, or sampling would cause missed business logic and broken refactoring.

Refactoring Directions

PA → PO (Extract Business Logic)

  • Removes UI code: forms, grids, item/form calls, color/font/style operations, and form callbacks.
  • Preserves business logic: data-access operations, queries, calculations, validations, state checks, and transaction management.
  • Creates bridge methods on the business-object class as replacements for free functions that mix UI and logic.
  • Converts grid cell reads to data-access reads and form variables to class member variables.

PO → PA (Create UI Wrapper)

  • Generates PA scaffolding: form draw, init, close, button, change, attribute, security, and grid callbacks.
  • Creates form variable setup and grid bindings mapping data-access columns to grid columns.
  • Generates grid population code and wires business-object methods into button/menu callbacks.

Code Quality Guarantees

  • Preserves error-handling and return patterns and maintains transaction boundaries.
  • Retains version feature flags and does not alter database query logic, joins, or WHERE clauses.
  • Enforces coding standards: naming, memory safety, Allman braces, and functions ≤ 100 lines.

Code Review Handoff

After producing the refactored file, the agent automatically hands off to the Code Review agent, which validates C/C++ standards (error handling, naming, memory safety, no UI residue, function size). Review reports are saved to /code_review_reports/.
